# Movie Recommender System

A content-based movie recommendation system that recommends similar movies using cosine similarity.

## Overview

This project uses movie metadata and text-based features to find movies that are similar to a movie selected by the user.

The recommendation system uses:
- Python
- Pandas
- Scikit-learn
- Cosine Similarity
- Streamlit
- TMDB API

## Features

- Select a movie and get similar movie recommendations
- Uses content-based filtering
- Displays movie posters using the TMDB API
- Interactive Streamlit interface
- Text features are processed using TF-IDF/vectorization
